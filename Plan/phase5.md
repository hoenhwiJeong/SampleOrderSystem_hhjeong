## 테스트 시나리오

### 5-1. 정상 플로우 — 재고 충분

```
순서
1. 시료 등록: S-001, 실리콘 웨이퍼-8인치, 재고 100 ea
2. 주문 접수: S-001, SK하이닉스, 수량 50 ea
3. 주문 승인 → CONFIRMED 확인, 재고 50 ea 확인
4. 출고 처리 → RELEASED 확인
```

| 검증 항목 | 기대값 | 결과 |
|-----------|--------|------|
| 승인 후 주문 상태 | CONFIRMED | ⬜ |
| 승인 후 재고 | 50 ea | ⬜ |
| 출고 후 주문 상태 | RELEASED | ⬜ |
| 모니터링 RELEASED 건수 | 1건 | ⬜ |

---

### 5-2. 정상 플로우 — 재고 부족

```
순서
1. 시료 등록: S-002, GaN 에피택셜-4인치, 수율 0.78, 평균생산시간 0.3 min, 재고 30 ea
2. 주문 접수: S-002, LG이노텍, 수량 100 ea
3. 주문 승인 → PRODUCING 확인, 생산라인 등록 확인
   - 부족분: 100 - 30 = 70 ea
   - 실 생산량: ceil(70 / (0.78 × 0.9)) = ceil(70 / 0.702) = ceil(99.7) = 100 ea
   - 총 생산시간: 0.3 × 100 = 30 min
4. 생산라인 조회 → 실 생산량 100 ea / 30 min 표시 확인
5. 생산 완료 처리 → CONFIRMED 확인
   - 새 재고: 30 + 100 - 100 = 30 ea
6. 출고 처리 → RELEASED 확인
```

| 검증 항목 | 기대값 | 결과 |
|-----------|--------|------|
| 승인 후 주문 상태 | PRODUCING | ⬜ |
| 생산라인 실 생산량 | 100 ea | ⬜ |
| 생산라인 총 생산시간 | 30 min | ⬜ |
| 생산 완료 후 주문 상태 | CONFIRMED | ⬜ |
| 생산 완료 후 재고 | 30 ea | ⬜ |
| 출고 후 주문 상태 | RELEASED | ⬜ |

### 5-3. 주문 거절 플로우

### 5-4. 생산라인 FIFO 검증

```
순서
1. 재고 부족 주문 3건 연속 승인 (A, B, C 순)
2. 생산라인 조회 → 현재 처리: A, 대기 큐: [B, C] 확인
3. 생산 완료 처리 → 현재 처리: B, 대기 큐: [C] 확인
4. 생산 완료 처리 → 현재 처리: C, 대기 큐: [] 확인
5. 생산 완료 처리 → 현재 처리 없음, 대기 큐 없음 확인
```

| 검증 항목 | 기대값 | 결과 |
|-----------|--------|------|
| 최초 현재 처리 | A(첫 번째 승인) | ⬜ |
| 1회 완료 후 현재 처리 | B | ⬜ |
| 2회 완료 후 현재 처리 | C | ⬜ |
| 3회 완료 후 상태 | 생산라인 비어있음 | ⬜ |

### 5-5. 모니터링 재고 상태 검증

```
순서
1. 시료 S-A: stock=0 → 고갈 확인
2. 시료 S-B: stock=30, CONFIRMED 주문 합산=50 → 부족 확인
3. 시료 S-C: stock=200, CONFIRMED 주문 합산=50 → 여유 확인
```

| 검증 항목 | 기대값 | 결과 |
|-----------|--------|------|
| stock=0 상태 | 고갈 | ⬜ |
| stock < confirmedTotal | 부족 | ⬜ |
| stock ≥ confirmedTotal (stock > 0) | 여유 | ⬜ |
