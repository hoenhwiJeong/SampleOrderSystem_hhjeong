## 레이아웃 상세

### 상단 상태 바
```
 생산라인  1개  (단일 라인)    현재 상태: [RUNNING]
```
- `[RUNNING]`: Orange Bold 뱃지

### 현재 처리 중 박스 (Box Drawing)
```
┌─────────────────────────────────────────────────────────┐
│  주문번호   {id}    시료   {시료명}                        │
│  주문량     {qty} ea    재고  {stock} ea  →  부족  {shortage} ea  │
│  실생산량   {actualProd} ea   (수율 {yield} / {time} min) │
│  진행       {progressBar}  완료 예정  {HH:MM}             │
└─────────────────────────────────────────────────────────┘
```
- 박스 테두리: Blue 컬러 Unicode Box Drawing 문자
- `부족 N ea`: Orange 컬러
- 진행 퍼센트: `ConsoleUI::progressBar(pct)`

### 대기 테이블
```
컬럼 너비 (setw):
순서     : 8
주문번호 : 14
시료     : 22
주문량   : 10
부족분   : 10
실생산량 : 10
예상완료 : 8
```

### 하단 주석
```cpp
// Gray 컬러로 공식 설명
" * 부족분 = 주문량 - 재고,  실생산량 = ceil(부족분 / (수율 × 0.9))\n"
" * 선입선출(FIFO) 방식으로 처리됩니다.\n"
```

### 액션 버튼
- 현재 처리 중 작업이 있을 때만 `[C]` 표시
- 없으면 `[0] 뒤로` 만 표시

## ConsoleUI 구현 포인트

```cpp
// 상태 바
std::cout << " 생산라인  1개  (단일 라인)    현재 상태: "
          << Color::ORANGE << Color::BOLD << "[RUNNING]" << Color::RESET << "\n";
ConsoleUI::printThinLine();

// 현재 처리 중 박스
std::cout << Color::ORANGE << Color::BOLD << " ▶ 현재 처리 중\n" << Color::RESET;
std::cout << Color::BLUE << "┌" << std::string(57, '-') << "┐\n" << Color::RESET;

std::cout << Color::BLUE << "│" << Color::RESET
          << "  주문번호   " << t.orderId
          << "    시료   " << t.sampleName << "\n";

std::cout << Color::BLUE << "│" << Color::RESET
          << "  주문량     " << t.orderQuantity << " ea"
          << "    재고  " << currentStock << " ea  →  부족  "
          << Color::ORANGE << t.shortage << " ea" << Color::RESET << "\n";

std::cout << Color::BLUE << "│" << Color::RESET
          << "  실생산량   " << t.actualProduction << " ea"
          << "   (수율 " << yieldRate << " / " << (int)t.totalTime << " min)\n";

std::cout << Color::BLUE << "│" << Color::RESET
          << "  진행       " << ConsoleUI::progressBar(pct)
          << "    완료 예정  " << estTime << "\n";

std::cout << Color::BLUE << "└" << std::string(57, '-') << "┘\n" << Color::RESET;

// 주석
ConsoleUI::printThinLine();
std::cout << Color::GRAY
          << " * 부족분 = 주문량 - 재고,  실생산량 = ceil(부족분 / (수율 × 0.9))\n"
          << " * 선입선출(FIFO) 방식으로 처리됩니다.\n"
          << Color::RESET;

// 액션
ConsoleUI::printThinLine();
std::cout << Color::GREEN  << " [C] 생산 완료 처리" << Color::RESET
          << "    [0] 뒤로\n";
ConsoleUI::prompt("선택");
```
