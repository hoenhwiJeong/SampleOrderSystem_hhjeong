## 색상 / 스타일

| 요소 | 색상 | ANSI 코드 |
|------|------|-----------|
| 섹션 헤더 `[1] 시료 관리` | Blue Bold | `\x1b[1;38;2;108;182;255m` |
| 구분선 `═══` | Gray | `\x1b[38;2;100;100;100m` |
| 구분선 `───` | Gray | `\x1b[38;2;100;100;100m` |
| 테이블 헤더 (ID, 시료명...) | Blue Bold | `\x1b[1;38;2;108;182;255m` |
| 데이터 행 ID (S-001 등) | Cyan/Blue | `\x1b[38;2;108;182;255m` |
| 데이터 행 시료명 | Blue | `\x1b[38;2;108;182;255m` |
| 나머지 데이터 | White | 기본 흰색 |
| 프롬프트 `선택 >` | Blue | `\x1b[38;2;108;182;255m` |

## 레이아웃 상세

### 서브 메뉴 바
- 한 줄에 `[1] 시료 등록   [2] 시료 목록   [3] 시료 검색   [0] 뒤로` 나열
- 각 항목 사이 탭(3~4칸) 간격

### 테이블 헤더
```cpp
// 컬럼 너비 (setw)
ID        : 10
시료명    : 24
평균생산시간 : 14
수율      : 8
현재재고  : 10
```

### 테이블 데이터 행
- ID 컬럼: Blue 컬러 적용 (`\x1b[38;2;108;182;255m`)
- 시료명 컬럼: Blue 컬러 적용
- 숫자 데이터: 기본 흰색

### 페이징 영역
```
 ...외 N종    [N] 다음페이지
 선택 > _
```
- 마지막 페이지이면 `[N] 다음페이지` 숨김

## ConsoleUI 구현 포인트

```cpp
// 헤더 출력
ConsoleUI::printLine();   // ══════
std::cout << Color::BLUE << Color::BOLD << " [1] 시료 관리\n" << Color::RESET;
ConsoleUI::printThinLine(); // ──────

// 서브메뉴 한 줄 출력
std::cout << " [1] 시료 등록   [2] 시료 목록   [3] 시료 검색   [0] 뒤로\n";
ConsoleUI::prompt("선택");

// 테이블 헤더 (Blue Bold)
std::cout << Color::BLUE << Color::BOLD
          << " " << std::left
          << std::setw(10) << "ID"
          << std::setw(24) << "시료명"
          << std::setw(14) << "평균 생산시간"
          << std::setw(8)  << "수율"
          << "현재 재고"
          << Color::RESET << "\n";
ConsoleUI::printThinLine();

// 데이터 행
for (const auto& s : page) {
    std::cout << " "
              << Color::BLUE  << std::left << std::setw(10) << s.id
              << Color::BLUE  << std::setw(24) << s.name
              << Color::RESET << std::setw(14) << (std::to_string(s.avgProductionTime) + " min/ea")
                              << std::setw(8)  << s.yieldRate
                              << s.stock << " ea\n";
}

// 페이징
ConsoleUI::printThinLine();
if (hasMore)
    std::cout << " ...외 " << remaining << "종    [N] 다음페이지\n";
ConsoleUI::prompt("선택");
```
