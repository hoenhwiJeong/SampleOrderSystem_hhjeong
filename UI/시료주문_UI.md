## 색상 / 스타일

| 요소 | 색상 | ANSI 코드 |
|------|------|-----------|
| 섹션 헤더 `[2] 시료 주문` | Blue Bold | `\x1b[1;38;2;108;182;255m` |
| 입력 레이블 `시료 ID`, `고객명`, `주문 수량` | White | 기본 |
| 프롬프트 `>` | Blue | `\x1b[38;2;108;182;255m` |
| `입력 내용 확인` 소제목 | White Bold | `\x1b[1m` |
| 확인 항목 레이블 | Gray | `\x1b[38;2;100;100;100m` |
| 확인 항목 값 | White | 기본 |
| `[Y] 예약 접수` | Green | `\x1b[38;2;34;197;94m` |
| `[N] 취소` | Gray | `\x1b[38;2;100;100;100m` |
| `예약 접수 완료.` | Green | `\x1b[38;2;34;197;94m` |
| `RESERVED` 뱃지 | Blue 배경 스타일 | `ConsoleUI::statusBadge("RESERVED")` |
| `※` 안내 문구 | Gray | `\x1b[38;2;100;100;100m` |

## 레이아웃 상세

### 입력 영역 (3개 필드)
```
 시료 ID   > [입력]
 고객명    > [입력]
 주문 수량 > [입력]
```
- 레이블 너비 고정 (setw(10)): `시료 ID  `, `고객명   `, `주문 수량`
- `>` 는 Blue 컬러 프롬프트 역할

### 확인 영역
- `──────` 구분선 후 `입력 내용 확인` 소제목
- 3줄: 시료(시료명 + ID 괄호), 고객, 수량
- 레이블 컬럼 너비 고정 (setw(8))

### Y/N 선택
```
 [Y] 예약 접수    [N] 취소
 선택 > _
```
- `[Y]`는 Green, `[N]`은 Gray

### 결과 영역
- `예약 접수 완료.` — Green 텍스트
- 빈 줄 후 주문번호 / 현재 상태 2줄
- `RESERVED` 뱃지: `ConsoleUI::statusBadge("RESERVED")`
- `※` 안내 문구: Gray

## ConsoleUI 구현 포인트

```cpp
// 입력 프롬프트
std::cout << " 시료 ID   ";
ConsoleUI::prompt(""); // "> " 출력
std::getline(std::cin, in.sampleId);

// 확인 섹션
ConsoleUI::printThinLine();
std::cout << " 입력 내용 확인\n";
std::cout << " 시료     " << s.name << "  (" << in.sampleId << ")\n";
std::cout << " 고객     " << in.customerName << "\n";
std::cout << " 수량     " << in.quantity << " ea\n\n";

std::cout << Color::GREEN << " [Y] 예약 접수" << Color::RESET
          << "    "
          << Color::GRAY  << "[N] 취소"      << Color::RESET << "\n";
ConsoleUI::prompt("선택");

// 결과 출력
ConsoleUI::printThinLine();
std::cout << "\n " << Color::GREEN << "예약 접수 완료." << Color::RESET << "\n\n";
std::cout << " 주문번호    " << o.id << "\n";
std::cout << " 현재 상태   " << ConsoleUI::statusBadge("RESERVED") << "\n\n";
std::cout << Color::GRAY
          << " ※ 재고 확인은 [3] 승인 메뉴에서 직접 진행하세요."
          << Color::RESET << "\n";
```
